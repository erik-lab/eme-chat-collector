eMe Chat Collector

Copies your own AI chat conversations into your own eMe instance. Nothing is collected until you fill this in and switch a provider on.

Your eMe

The URL your eMe API answers on, which is often not the one you open in a browser — the bare address usually serves the web client, with the API under a path such as /v2/api. If a sync reports that an HTML page came back, this is the field to fix.

Stored in this browser profile only. The key is currently unscoped — see the README before putting one anywhere you would mind losing.

Collect from

Re-send everything forgets what has already been sent, so the next sync sends every conversation again. Use it when eMe has learned to read something the extension was already sending — the records are stale but nothing looks out of date. It cannot duplicate anything: each conversation is keyed on its own id and updates in place.
